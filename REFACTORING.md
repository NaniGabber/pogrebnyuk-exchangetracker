# Refactoring Notes

## Зміна поведінки поля rate

### До рефакторингу

Некоректні значення поля `rate` перетворювалися на `0`.

Приклад:

{
    "asset": "CHF",
    "type": "currency",
    "rate": "сорок два",
    "date": "2026-10-10"
}

Результат:

rate = 0

### Після рефакторингу

Некоректні значення поля `rate` перетворюються на `None`.

Результат:

rate = None

### Причина

Значення `0` є коректним числовим значенням курсу, тоді як `None` означає, що курс відсутній або не може бути перетворений на число. Це дозволяє розрізняти реальне значення курсу та помилкові або відсутні дані.
