# Refactoring Notes

## Зміна поведінки поля rate

### До рефакторингу

Некоректні значення поля `rate` перетворювалися на `0`.

Приклад:

{
    "asset": "CHF",
    "type": "currency",
    "rate": "сорок два",
    "date": "2026-10-10"
}

Результат:

rate = 0

### Після рефакторингу

Некоректні значення поля `rate` перетворюються на `None`.

Результат:

rate = None

### Причина

Значення `0` є коректним числовим значенням курсу, тоді як `None` означає, що курс відсутній або не може бути перетворений на число. Це дозволяє розрізняти реальне значення курсу та помилкові або відсутні дані.

## Компроміс під час дедуплікації

Під час рефакторингу логіку дедуплікації було винесено в окрему функцію `deduplicate()`.

Для визначення дублікатів використовується ключ:

(asset, asset_type, date)

Це означає, що записи з однаковою валютою або металом, типом та датою вважаються дублікатами і зберігається лише перший із них.

Такий підхід є компромісом. Він дозволяє зберегти поточну поведінку системи та уникнути появи повністю однакових записів у результатах обробки. Водночас система не аналізує інші поля запису під час пошуку дублікатів. Тому записи з однаковим ключем, але відмінними значеннями курсу, також вважатимуться дублікатами.

Наведений варіант свідомо зберігає цю поведінку для забезпечення сумісності з існуючою логікою застосунку.

## Порівняння жадібного та лінивого читання JSONL

Для тестування було згенеровано файл `data/large.jsonl`, що містить 200 000 записів.

Результати вимірювань:

### Lazy loading (generator)

- Час виконання: 1.305 с
- Пікове споживання пам'яті: 0.82 МБ

### Eager loading (list)

- Час виконання: 1.581 с
- Пікове споживання пам'яті: 103.03 МБ

### Висновок

Лінивий варіант використовує генератор і тримає в пам'яті лише один поточний запис. Жадібний варіант завантажує всі 200 000 записів у список, тому споживає значно більше оперативної пам'яті.

Експеримент підтвердив, що використання генераторів дозволяє суттєво зменшити споживання пам'яті при роботі з великими наборами даних. Різниця між підходами становить кілька порядків за обсягом використовуваної пам'яті.
