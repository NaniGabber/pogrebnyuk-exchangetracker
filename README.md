# Exchange Tracker

## Description

This application retrieves live exchange rates and precious metal prices.  
It provides a tracker for major currency pairs (UAH‑USD, EUR‑USD‑UAH, GBP‑USD‑UAH, JPY‑USD‑UAH) as well as precious metals (Gold, Silver, Platinum, Palladium) quoted against USD and converted to UAH.

## Installation

### 1. Clone the repository:
```bash
git clone https://NaniGabber/pogrebnyuk-exchangetracker.git
cd pogrebnyuk-exchangetracker
```
### 2. Create and activate a virtual environment:
```bash
python -m venv .venv
source .venv/bin/activate   # Linux/Mac
.venv\Scripts\activate      # Windows
```
### 3. Install the project in editable mode with development dependencies:
```bash
pip install -e ".[dev]"
```
## Usage
Run the simply command:
```bash
exchangetracker
```
